## 1. Primary Telemetry Dataset: `Battery_data.csv`

[`Battery_data.csv`](file:///C:/Users/desai/Desktop/Batery%20Analyzer/Battery_data.csv) contains experimental battery discharge telemetry recorded during a constant-current discharge test of a single-cell Lithium-ion battery (rated $2.0\,\text{Ah}$ nominal capacity).

### File Format & Structure
* **Encoding**: UTF-8 plain text, comma-separated values (`CSV`).
* **Header**: Line 1 defines the 3 fundamental telemetry channels:
  ```csv
  Time,Voltage,Current
  ```
* **Data Rows**: 80 records spanning from $t = 0\,\text{s}$ to $t = 790\,\text{s}$ at a uniform sample rate of $\Delta t = 10.0\,\text{s}$.

### Physical Electrochemical Phases in the Dataset
```text
Time (s)     Voltage (V)    Current (A)    Electrochemical Regime
0            4.20           2.00           Full State of Charge (Resting OCV / Start)
10 - 50      4.18 - 4.14    2.05 - 1.97    Initial Ohmic Drop & Surface Charge Depletion
60 - 590     4.13 - 3.60    2.03 - 1.89    Stable Working Plateau (Phase transition)
600 - 680    3.58 - 3.42    1.86 - 1.78    Depletion Knee Onset (Steepening gradient)
690 - 790    3.40 - 3.20    1.75 - 1.50    Terminal Depletion & Safe Cutoff (3.20V)
```

1. **Initial State ($t=0$, $4.20\,\text{V}$)**:
   * Represents the standard charging ceiling for typical Lithium-ion NMC / Cobalt chemistries.
2. **Initial Ohmic Drop ($t=0 \rightarrow 10\,\text{s}$)**:
   * Voltage steps from $4.20\,\text{V}$ down to $4.18\,\text{V}$ as a $\sim 2\,\text{A}$ current is drawn.
   * Indicates an initial internal DC resistance $R_{dc} \approx \frac{0.02\,\text{V}}{2.00\,\text{A}} \approx 10\,m\Omega$.
3. **Working Plateau ($t=60 \rightarrow 590\,\text{s}$, $4.13\,\text{V} \rightarrow 3.60\,\text{V}$)**:
   * The cell maintains a steady voltage over ~530 seconds, delivering over $75\%$ of its total energy at an average of $\sim 3.8\,\text{V}$.
4. **Knee Inflection ($t=600\,\text{s}$, $V \le 3.58\,\text{V}$)**:
   * The electrochemical active materials are depleted, and diffusion limitations inside the electrode particles cause voltage to drop rapidly.
5. **Cutoff Termination ($t=790\,\text{s}$, $V = 3.20\,\text{V}$)**:
   * Terminal voltage reaches the preset safe discharge limit ($3.20\,\text{V}$), preventing copper dissolution or permanent cell damage.

## 2. Interactive Web Report: `battery_report.html`

[`battery_report.html`](file:///C:/Users/desai/Desktop/Batery%20Analyzer/battery_report.html) is an executive, self-contained interactive web report generated by [`export_html_report()`](file:///C:/Users/desai/Desktop/Batery%20Analyzer/battery_engine.py#L295). It can be opened in any modern browser without a web server or backend.

### Architecture & Dependencies
* **HTML5 & CSS3**: Pure semantic markup and responsive CSS custom properties (variables) with CSS Grid and Flexbox.
* **Chart.js (v4 CDN)**: Loaded via `<script src="https://cdn.jsdelivr.net/npm/chart.js"></script>` to provide animated, interactive hardware-accelerated canvas charts with tooltips and crosshairs.
* **Zero Backend Requirement**: All telemetry points are directly injected into the HTML document as JavaScript arrays by Python during report export.

### Visual Components Breakdown

#### 1. CSS Theme System (Lines 8–75)
```css
:root {
    --bg-main: #0b0f17;
    --bg-card: #161f30;
    --bg-card-hover: #1e2a42;
    --border-color: #2a364f;
    --text-main: #f8fafc;
    --text-muted: #94a3b8;
    --cyan: #00e5ff;
    --emerald: #10b981;
    --amber: #f59e0b;
    --rose: #ef4444;
    --purple: #a855f7;
    --orange: #f97316;
}
```
* Centralized color palette matching the desktop GUI aesthetic.
* Card hover animations and responsive layouts with `repeat(auto-fit, minmax(...))`.

#### 2. Header & KPI Cards (Lines 80–125)
* Displays source filename, total test duration ($s$ and $min$), point count, and dynamic cell health badge (e.g. `Grade B (Good)` with color coding).
* 5 Grid KPI Cards:
  * **Voltage Range**: Initial $\rightarrow$ Final voltage, total $\Delta V$, cutoff threshold.
  * **Delivered Capacity**: High-precision $Ah$, $mAh$, and % of nominal rating.
  * **Delivered Energy**: $Wh$, $mWh$, and thermodynamic mean voltage.
  * **Current & Power**: Average/peak current and power, peak C-rate.
  * **Internal Resistance**: Median $R_{dc}$, final sag resistance, plateau duration.

#### 3. Interactive Chart Grid (Lines 127–146)
* 4 responsive Chart.js canvas elements arranged in a $2 \times 2$ grid:
  1. `<canvas id="voltageChart">`: Voltage vs. Time with cyan gradient fill.
  2. `<canvas id="currentPowerChart">`: Dual-axis line chart showing Current ($A$, left axis) and Power ($W$, right axis).
  3. `<canvas id="capacityChart">`: Capacity accumulation ($mAh$).
  4. `<canvas id="socChart">`: State of Charge depletion ($100\% \rightarrow 0\%$).

#### 4. Analytical Telemetry Table (Lines 148–177)
* Tabulates all baseline electrical and electrochemical parameters (resting voltage, cutoff voltage, thermodynamic mean voltage, sag, high-precision vs. rectangular integration, peak loads, median $R_{dc}$, and plateau duration).

#### 5. Embedded Chart.js Script (Lines 186–277)
* Injected JavaScript arrays:
  * `const labels = ["0s", "10s", "20s", ...];`
  * `const vData = [4.2, 4.18, 4.17, ...];`
  * `const iData = [2.0, 2.05, 2.02, ...];`
  * `const pData = [8.4, 8.57, 8.42, ...];`
  * `const capData = [0.0, 5.6, 11.2, ...];`
  * `const socData = [100.0, 98.7, 97.3, ...];`
* Configures Chart.js axes, dark slate grid lines (`#1e293b`), custom tooltips, and dual $y$-axis scales (`y` and `y1`).
